# 小智 · AI 个人生活系统

这是小智的第一版概念网站，当前是一个可直接部署到 GitHub Pages 的静态站点。

## 当前版本包含

- 首页定位：把记忆、计划与行动放在同一处
- 三个核心模块：Memory、Today、Reflect
- “今日视图”产品预览
- 可操作的“快速记录”弹窗，用于验证最小交互闭环
- 响应式布局、键盘操作、减少动态效果支持

## 本地查看

直接打开 `index.html` 即可查看，也可以在当前目录启动一个静态文件服务器。

## 发布到 GitHub Pages

将整个目录推送到 GitHub 仓库后，在仓库设置中选择 Pages，发布来源选择默认分支的根目录即可。

本页使用一张项目本地的主视觉图片，位于 `assets/xiaozhi-hero.png`。`sources/` 是项目资料镜像，保持只读。
